# Security Policy

## Scope

This repository provides a tvOS 17.0 port of TrollStore for user-owned Apple TV 4K hardware.

- No personal credentials, device identifiers, private developer keys, or prebuilt exploit/OpenSSL binaries are committed to this repository.
- This port does not modify `/Applications` on the sealed system volume by default.

## Reporting a Vulnerability

If you discover a security issue, unsafe privilege handling, or accidental secret/PII exposure in this repository:

1. Do **not** disclose credentials, device UDIDs, or personal infrastructure details in a public issue.
2. Contact the maintainer privately via GitHub Security Advisories or direct private channel.
